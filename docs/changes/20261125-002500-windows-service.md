### Added
- On Windows, the server runs as a Windows service when the service control manager starts it, and writes its log to `logs\prusa-connect.log` in the folder that `-workdir` names. See [ADR-20261125-jqp](../decisions/20261125-jqp-prusa-connect-runs-as-a-windows-service-that-an-installer.md).
- The `-workdir` flag names the folder the server runs in. `-config` and the relative paths in the configuration resolve from it.
- A file named `managed-by-installer` beside the executable hands upgrades to the installer: the Updates page prepares the release but does not replace the executable.
