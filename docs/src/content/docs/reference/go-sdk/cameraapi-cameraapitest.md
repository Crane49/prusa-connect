`cameraapitest` is the conformance suite a camera driver passes.
`RunCameraContract` builds the camera once per subtest and holds it to the
clauses a host cannot work around:

- the declared format set does not change under the host
- a snapshot's media type is the one its format means
- a stream's `Read` returns when the host closes it
- `Close` stops the stream and leaves no goroutine behind

Start the device fixture outside the factory. One subtest counts goroutines
across a build and a `Close`, and a fixture started inside the factory would
be counted as the driver's own.

```go
package acmecam

import (
	"net/http"
	"net/http/httptest"
	"testing"

	"github.com/prusa3d/prusa-connect/sdk/cameraapi"
	"github.com/prusa3d/prusa-connect/sdk/cameraapi/cameraapitest"
)

// jpeg is the smallest JPEG a decoder accepts: a start marker and an end marker.
var jpeg = []byte{0xFF, 0xD8, 0xFF, 0xD9}

func TestContract(t *testing.T) {
	// The device is started once, outside the factory, because one subtest
	// counts goroutines across a build and a Close.
	device := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, _ *http.Request) {
		w.Header().Set("Content-Type", "image/jpeg")
		_, _ = w.Write(jpeg)
	}))
	t.Cleanup(device.Close)

	cameraapitest.RunCameraContract(t, func(t *testing.T) cameraapi.Camera {
		c, err := newCamera(cameraapi.ProviderSpec{
			Type:    "acme-snapshot",
			Printer: "mk4-01",
			Config:  map[string]any{"snapshot_url": device.URL},
		})
		if err != nil {
			t.Fatal(err)
		}

		return c
	})
}
```

## `cameraapi/cameraapitest` {#cameraapi-cameraapitest}

```go
import "github.com/prusa3d/prusa-connect/sdk/cameraapi/cameraapitest"
```

Package cameraapitest provides the conformance suite every cameraapi.Camera must pass, so a driver written by a community author behaves the way the media plane needs it to and the built-in ones do not get to be special.

The clauses it holds are the ones a host cannot work around. A declared format set that changes under the host makes negotiation meaningless; a snapshot whose media type is not the one its format means is a media type a browser acts on; a stream whose Read does not return when the host closes it is a goroutine per abandoned viewer; and a Close that does not stop the stream is a device socket held for the life of the process.

Usage from a driver's \_test.go:

	func TestContract(t *testing.T) {
	    device := somefixture.Start(t)
	    cameraapitest.RunCameraContract(t, func(t *testing.T) cameraapi.Camera {
	        c, err := New(cameraapi.ProviderSpec{Type: Type, Printer: "p", Config: map[string]any{
	            "snapshot_url": device.SnapshotURL(),
	        }})
	        if err != nil { t.Fatal(err) }
	        return c
	    })
	}

The device is started once, outside newCamera, because one subtest compares the live goroutines across a build and a Close and a fixture started inside newCamera would be read as the driver's own.

### `RunCameraContract` {#cameraapi-cameraapitest-runcameracontract}

```go
func RunCameraContract(t *testing.T, newCamera NewCamera)
```

RunCameraContract runs every clause of cameraapi.Camera against newCamera.

### `NewCamera` {#cameraapi-cameraapitest-newcamera}

```go
type NewCamera func(t *testing.T) cameraapi.Camera
```

NewCamera builds the camera under test. It is called once per subtest, so a driver that cannot be built twice fails here rather than intermittently.
