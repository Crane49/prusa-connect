`routesapi` is the HTTP surface a module serves. A module opens no port. The
host receives the request, resolves the caller, decides the permission on the
module's instance, and only then calls `routes.serve` over the wire with the
request inside. The host mounts the module under
`/api/v1/modules/<namespace>/`, or at a root prefix the operator names.

A module writes ordinary `net/http`. `Serve` adapts a handler onto
`MethodServe` against an in-memory recorder, so nothing about the wire shows
in a handler. Paths are relative to the mount: a module writes `/spools` and
is reached at `/api/v1/modules/<namespace>/spools`. `PrincipalOf` answers who
the host authorized, and it is the host's answer, not a header the caller
set. A module that serves routes also ships an OpenAPI fragment describing
them, attached to its `plugin.info` answer with `Describe`. The host serves
the fragment rebased under the mount, which is what a client generator reads.

```go
package shelf

import (
	"context"
	_ "embed"
	"encoding/json"
	"net/http"

	"github.com/prusa3d/prusa-connect/sdk/routesapi"
	"github.com/prusa3d/prusa-connect/sdk/wirerpc"
)

// openAPI describes the routes below, with every path relative to the mount.
//
//go:embed openapi.json
var openAPI []byte

// info answers plugin.info with the fragment attached, which is what makes
// the host mount the routes.
func info(context.Context, wirerpc.Call) (any, error) {
	return routesapi.Describe(wirerpc.Info{Name: "spool-shelf", Version: "0.1.0", Contract: wirerpc.Contract}, openAPI)
}

// routes is ordinary net/http. /spools here is reached at
// /api/v1/modules/<namespace>/spools, and the host decided who may call it.
func routes() http.Handler {
	mux := http.NewServeMux()

	mux.HandleFunc("GET /spools", func(w http.ResponseWriter, r *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		_ = json.NewEncoder(w).Encode(map[string]any{
			"spools":   []string{"petg-black", "pla-galaxy"},
			"asked_by": routesapi.PrincipalOf(r),
		})
	})

	return mux
}

// methods is the whole method set a module with routes answers.
func methods() wirerpc.Methods {
	return wirerpc.Methods{
		wirerpc.MethodInfo:     info,
		wirerpc.MethodShutdown: func(context.Context, wirerpc.Call) (any, error) { return nil, nil },
		routesapi.MethodServe:  routesapi.Serve(routes()),
	}
}
```

Every operation in the fragment needs an `operationId`, a `summary` and a
`description`, or the host refuses the module at start. A request body and a
response body are each bounded by `MaxModuleBody`, 1 MiB. A module that moves
a file uses a stream.

```go
type CallParams struct {
    // Module is the namespace of the module to call, the segment its routes
    // are mounted under: /api/v1/modules/<namespace>.
    Module string `json:"module"`
    // Principal is who the call runs as. Empty is the calling module itself.
    // A person may be named only while the host is serving that person's

    // Method is the HTTP method.

    // Path is the route relative to the other module's mount, as an escaped
    // URL path starting with "/", such as /jobs. It must stay inside the
    // mount: no "." or ".." segment, no empty segment, no backslash, no

    Path    string              `json:"path"`
    Query   string              `json:"query,omitempty"`
    Headers map[string][]string `json:"headers,omitempty"`
    // Body is at most MaxModuleBody bytes, as a request a person makes.
    Body []byte `json:"body,omitempty"`
}
```

CallParams is the params of MethodCall.

### `Request` {#routesapi-request}

```go
type Request struct {
    Method    string              `json:"method"`
    Path      string              `json:"path"`
    Query     string              `json:"query,omitempty"`
    Headers   map[string][]string `json:"headers,omitempty"`
    Body      []byte              `json:"body,omitempty"`
    BodyFile  string              `json:"body_file,omitempty"`
    Principal string              `json:"principal"`
}
```

Request is one HTTP request as a module receives it.

Path is relative to the mount: a module writes /spools and is reached at /api/v1/modules/\<namespace>/spools. It never includes the mount. It is decoded, as net/http's URL.Path is, and HTTP sets it on the request as it is, without parsing it again: the host matched its routes against this exact path.

Principal is who the host authorized. The host sets it, not the caller. It is empty on a route the manifest lists under routes.public.

BodyFile is set on a route the manifest lists under routes.staged, and Body is then empty. It is the path of the file holding the body, relative to the module's data directory, such as staged/MZXW6YTBOI4DQMZTGQ2TMNZYHE. The host deletes the file once the module answers, so a module that keeps the body moves the file first.
