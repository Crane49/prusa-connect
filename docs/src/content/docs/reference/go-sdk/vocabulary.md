`vocabulary` is the deprecation marker that an entry of a published set can
have. A published set is a closed list that a client depends on: the error
codes, the event types, the resource kinds, the authorization actions. An
entry is never removed without warning. A release first marks it with a
`Deprecation`, and a later release removes it.

Use this package when you read one of those sets in Go and want to warn about
an entry that is going away. Use it too when your module publishes a set of
its own, so that your set has the same marker. The sets in
[`event`](./event.md), [`fault`](./fault.md),
[`extension`](./extension.md) and [`connectorapi`](./connectorapi.md) use it,
so one reader works for all of them.

A `Deprecation` has `Since`, the application release that first published the
marker, and `ReplacedBy`, the entry to move to. `ReplacedBy` is empty when
nothing replaces the entry. `Window` is how many minor releases an entry stays
published after `Since`. The marker is a pointer, and nil means the entry
stays. Every method is safe to call on nil.

```go
package spools

import (
	"encoding/json"
	"fmt"

	"github.com/prusa3d/prusa-connect/sdk/vocabulary"
)

// material is one entry of a set this module publishes. Deprecated is nil
// for an entry that stays.
type material struct {
	Name       string                  `json:"name"`
	Deprecated *vocabulary.Deprecation `json:"deprecated,omitempty"`
}

// materials renames "pet-g" to "petg" in release 0.4.0. The old name stays
// published, with the marker, for vocabulary.Window minor releases.
var materials = []material{
	{Name: "pla"},
	{Name: "petg"},
	{Name: "pet-g", Deprecated: vocabulary.Deprecate("0.4.0", "petg")},
}

// warn prints one line for every entry a client should move away from.
func warn() {
	for _, m := range materials {
		if !m.Deprecated.Deprecated() {
			continue
		}

		entry, _ := json.Marshal(m)
		fmt.Println(string(entry))
		// {"name":"pet-g","deprecated":{"since":"0.4.0","replaced_by":"petg"}}

		fmt.Println(m.Deprecated.Sentence())
		// Deprecated in 0.4.0. Use `petg` instead.
	}
}
```

This package removes nothing and enforces nothing. The compatibility check of
this repository reads the marker and allows a removal only after the window
has passed. The package does not list the sets either: each set is in the
package that owns it, and the server publishes them over
[the vocabularies API](../api/vocabularies.md).

## `vocabulary` {#vocabulary}

```go
import "github.com/prusa3d/prusa-connect/sdk/vocabulary"
```

Package vocabulary defines the deprecation marker that every published vocabulary uses.

A vocabulary is a closed set of names that a client depends on, such as the error codes, the event types, the resource kinds and the authorization actions. One release marks an entry as deprecated, and a later release removes it.

### `Window` {#vocabulary-window}

```go
const Window = 3
```

Window is the number of minor releases of the application that a deprecated entry stays published, counted from the release that deprecated it.

### `Deprecation` {#vocabulary-deprecation}

```go
type Deprecation struct {
    // Since is the application release that first published this marker,
    // written as three numbers such as 0.2.0. Window is counted from it.
    Since string `json:"since" doc:"The application release this entry was deprecated in."`
    // ReplacedBy is the name of the entry to use instead, in the same
    // vocabulary. It is empty when no entry replaces this one.
    ReplacedBy string `json:"replaced_by,omitempty" doc:"The entry to move to, when one takes over."`
}
```

Deprecation marks an entry that is still published and that a later release removes. An entry with no Deprecation is not deprecated. An entry is removed only after it had this marker for Window minor releases.

#### `Deprecate` {#vocabulary-deprecate}

```go
func Deprecate(since, replacedBy string) *Deprecation
```

Deprecate returns a marker with the given release and replacement.

#### `Deprecation.Deprecated` {#vocabulary-deprecation-deprecated}

```go
func (d *Deprecation) Deprecated() bool
```

Deprecated reports whether d marks a deprecation. It is false for a nil marker and for a marker with an empty Since.

#### `Deprecation.Sentence` {#vocabulary-deprecation-sentence}

```go
func (d *Deprecation) Sentence() string
```

Sentence returns the sentence a generated reference page prints under a deprecated entry. It returns an empty string when d marks no deprecation.
