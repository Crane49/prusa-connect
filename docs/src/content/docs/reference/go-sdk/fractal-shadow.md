`shadow` stores one node's copy of the state of the nodes below it. Prusa
Fractal calls that copy the shadow. The protocol and the other packages are
introduced on the [`fractal`](./fractal.md#prusa-fractal) page.

Use this package to read what the nodes below last reported: the temperature
of a printer two levels down, and whether that value is still current. Build a
`Store` with `New`, give it to [`node`](./fractal-node.md) as `Config.Shadow`,
and read it with `Get`, `Prop`, `Status` or `Subscribe`. The node writes every
report that arrives into the store, so an application with a node calls
`ApplyREP` and `MarkStale` only in a test.

A `Selection` says which interfaces the store keeps. `Interfaces` names them
one at a time by node path, interface name and instance id. `Patterns` selects
by interface name on every node below, and `*` matches any run of characters.
A store with an empty selection keeps nothing.

Every interface in the store has a status. `EMPTY` means it was named and
nothing has arrived. `OK` means the values are the last ones reported. `STALE`
means the connection to that node, or to a node on the way to it, was lost.
The values stay readable while stale, and the next report sets the status to
`OK` again.

```go
package watch

import (
	"encoding/json"
	"fmt"

	"github.com/prusa3d/prusa-connect/sdk/fractal"
	"github.com/prusa3d/prusa-connect/sdk/fractal/shadow"
)

func run() error {
	printer := shadow.Key{Node: "hq/brno/printer-1", Interface: "FDMPrinter1", Instance: "1"}

	// The store keeps the one named interface, and every Chamber interface
	// that any node below reports.
	store, err := shadow.New(shadow.Config{Selection: shadow.Selection{
		Interfaces: []shadow.Key{printer},
		Patterns:   []fractal.Pattern{"Chamber*"},
	}})
	if err != nil {
		return err
	}

	result := store.ApplyREP(fractal.REP{
		Version:   fractal.Version,
		Sender:    printer.Node,
		Interface: printer.Interface,
		Instance:  printer.Instance,
		Timestamp: 1751400000000,
		Props:     fractal.Props{"nozzleTemp": json.RawMessage(`25.0`)},
	})
	fmt.Println(result.Outcome, result.Previous, result.Status) // applied EMPTY OK

	// The connection to printer-1 is gone. The values stay and are marked STALE.
	store.MarkStale(printer.Node)

	snap, _ := store.Get(printer)
	fmt.Println(snap.Status, string(snap.Props["nozzleTemp"])) // STALE 25.0

	return nil
}
```

The store is in memory and is empty after a restart. The full state report
that a node requests when a connection comes up fills it again. Nothing
deletes a node's shadow until the application calls `RemoveNode`. A program that calls `Subscribe`
closes the subscription when it stops reading.

This package forwards no message and checks no value type. The node forwards,
and [`schema`](./fractal-schema.md) checks types.

## `fractal/shadow` {#fractal-shadow}

```go
import "github.com/prusa3d/prusa-connect/sdk/fractal/shadow"
```

Package shadow implements the shadow of one Fractal node: the copy a node keeps of the property values of interfaces on other nodes.

A Store is that copy. A Selection says which interfaces it keeps. For each one it has a Key, a Status (EMPTY, OK or STALE) and the last reported property values.

For the nodes below, pass each REP to ApplyREP and each LOS to ApplyLOS, and call MarkStale when the link to a node directly below is lost. The caller decides from the Result whether to forward a message.

For the nodes above, keep a second Store. Call Rebase each time the node takes a Node Path and MarkStaleAbove when a link above is lost.
