`printcompat` tells a module whether a print file fits a printer before it
sends the file. A module imports it when it picks a printer for a file, such
as a planner that queues prints across a fleet.

The module reads the printer with `device.get` or `device.list`, and passes the
model, the firmware and the state tree to `PrinterFromState`. It reads the
file with `storage.stat`, whose answer carries the file's needs as
`storageapi.PrintInfo`. `Evaluate` takes both and answers a `Verdict`: ok, a
warning the printer would stop at, or a refusal. Each finding names the rule,
the filament by its T number and the tool it lands on. It also says what the
file wants and what the printer has.

The rules are the checks the public Prusa firmware makes before a print
starts, and whether the print fits the build volume the driver reports. A
check whose facts are unknown is listed under `Unverified` and never counted
as passed. A tool with nothing loaded is a known state and fails the material
check. The package does no I/O, so it needs no permission of its own. The rules
are ADR-20261023-gna.

## `printcompat` {#printcompat}

```go
import "github.com/prusa3d/prusa-connect/sdk/printcompat"
```

Package printcompat says whether a print file fits a Prusa printer, the way the printer's firmware would judge it before it starts. It does no I/O.

PrinterFromState reads what a printer has from its state tree. storageapi.PrintInfo is what a print file needs. Evaluate compares the two and returns a Verdict.

The rules are the checks the public Prusa firmware makes before a print (gcode\_compatibility.cpp in Prusa-Firmware-Buddy), plus one of this package: whether the print fits the build volume. A check whose facts are unknown on either side is reported as unverified, never as passed.

#### `Evaluate` {#printcompat-evaluate}

```go
func Evaluate(file *storageapi.PrintInfo, printer Printer) Verdict
```

Evaluate compares what a file needs with what a printer has and says how the printer's firmware would take the print. The checks run in the order of the firmware, and the build volume check comes last. Each filament is checked on the tool that connectorapi.ToolTree.Resolve gives its T number. A nil file is OK.
