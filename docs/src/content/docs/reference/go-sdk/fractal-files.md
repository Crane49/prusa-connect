`files` holds the parts of the Fractal file distribution extension that
every node must read and write in the same way. A node names a file by the
hash of its bytes. The protocol and the other packages are introduced on the
[`fractal`](./fractal.md#prusa-fractal) page.

Use this package when your node publishes files to the nodes below it, or
fetches a file from the node above it. It reads no disk and opens no
connection.

```go
package shares

import "github.com/prusa3d/prusa-connect/sdk/fractal/files"

func link(benchy []byte) string {
	u := files.URL{ID: files.Sum(benchy), Name: "benchy.bgcode"}

	return u.String() // fractal:///sha256:...?name=benchy.bgcode
}
```

A directory is a `Listing`. Its identity is `Sum` of the bytes `Encode`
returns, and `DecodeListing` refuses every other encoding of the same
entries, so one directory has one identity.

```go
func publish(benchy []byte) (files.Identity, error) {
	listing := files.Listing{Entries: []files.Entry{{
		Name: "benchy.bgcode",
		Kind: files.KindFile,
		Size: uint64(len(benchy)),
		Hash: files.Sum(benchy),
	}}}

	encoded, err := listing.Encode()
	if err != nil {
		return files.Identity{}, err
	}

	return files.Sum(encoded), nil
}
```

`ParseText` and `ParseURL` refuse every other spelling of the same identity,
so one object has one name. `CheckName` does not check Normalization Form C,
because the standard library has no Unicode normalization. A node that takes
names from a disk converts them first, for example with
`golang.org/x/text/unicode/norm`.

A parent puts a `JoinEntry` in every grant, under `ExtensionName`, and a
child reads it with `ParseJoinEntry` before it connects. Pass `Definitions`
to `schema.Load`, as the [`prusa`](./fractal-prusa.md) page shows for the
printer interfaces. A node then checks every call of `List` against the
definition.

## `fractal/files` {#fractal-files}

```go
import "github.com/prusa3d/prusa-connect/sdk/fractal/files"
```

Package files defines what both ends of the Fractal file distribution extension must agree on: identities, listings, names, URLs and join data.

A file is named by the hash of its bytes, and a directory by the hash of its listing. A node publishes folders, and a node below fetches an object from its parent by that identity.

This package reads no disk and opens no connection. CheckName does not check Unicode Normalization Form C. A node that takes names from a disk must normalize them first, for example with golang.org/x/text.

Encode returns the listing in deterministic CBOR, version 1, with its entries sorted by the UTF-8 bytes of their names. The identity of the listing is Sum of the result.
