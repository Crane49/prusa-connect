An event sink is a compiled-in extension that receives the host's durable
events and does something else with them: posts them to a URL, or puts them
on a broker. `eventsapi` is the contract it implements. The core knows
nothing about what a sink does, and a sink knows the host's own envelope
only, through `Fact`.

The host builds a `Processor` from `ProviderSpec` through the factory given
to `Register`, then calls it from the event bus. `FactObserved` receives
every durable frame under the envelope it was published with: origin, type,
class, sequence and the payload unparsed. The five typed methods are the
older, narrower door and describe a few facts by name. The two doors are
independent, so a sink that wants everything implements `FactObserved` and
leaves the others empty. Telemetry never reaches a sink: it is superseded,
not kept.

Every method is fire-and-forget. The caller is the bus, so a method that
blocks holds up every other subscriber, and a method that panics takes the
process with it. A sink buffers and drops; it never waits.

```go
package acmehook

import (
	"bytes"
	"encoding/json"
	"errors"
	"net/http"
	"time"

	"github.com/prusa3d/prusa-connect/sdk/eventsapi"
	"github.com/prusa3d/prusa-connect/sdk/extension"
)

func init() {
	eventsapi.Register("acme-hook", extension.Doc{
		Summary:     "Posts every durable event to one URL",
		Description: "Sends each fact as JSON to url and drops what the destination does not take in time. It keeps nothing.",
		Version:     "0.1.0",
		Contract:    eventsapi.Contract,
		Stability:   extension.StabilityExperimental,
	}, func(spec eventsapi.ProviderSpec) (eventsapi.Processor, error) {
		url, _ := spec.Config["url"].(string)
		if url == "" {
			return nil, errors.New("acme-hook: url is required")
		}

		return newSink(url), nil
	})
}

// sink hands each fact to one goroutine over a bounded queue, so the bus is
// never held up by the destination.
type sink struct {
	url   string
	queue chan eventsapi.Fact
	done  chan struct{}
}

func newSink(url string) *sink {
	s := &sink{url: url, queue: make(chan eventsapi.Fact, 256), done: make(chan struct{})}
	go s.post()

	return s
}

// FactObserved never blocks: a full queue drops the fact.
func (s *sink) FactObserved(fact eventsapi.Fact) {
	select {
	case s.queue <- fact:
	default:
	}
}

func (s *sink) post() {
	defer close(s.done)

	client := &http.Client{Timeout: 5 * time.Second}

	for fact := range s.queue {
		body, err := json.Marshal(fact)
		if err != nil {
			continue
		}

		if resp, err := client.Post(s.url, "application/json", bytes.NewReader(body)); err == nil {
			_ = resp.Body.Close()
		}
	}
}

// The typed methods are served by FactObserved, which sees every durable frame.
func (*sink) PrinterStateChanged(eventsapi.PrinterState)   {}
func (*sink) PrinterLabelsChanged(eventsapi.PrinterLabels) {}
func (*sink) PrinterDeleted(string)                        {}
func (*sink) JobUpdated(eventsapi.JobInfo)                 {}
func (*sink) LabelDeleted(string)                          {}

// Close stops taking facts and waits for the queue to drain.
func (s *sink) Close() error {
	close(s.queue)
	<-s.done

	return nil
}
```

[`eventsapitest`](./eventsapi-eventsapitest.md) runs a sink against a
destination that accepts every connection and never answers, which is where
a method that waits shows.

## `eventsapi` {#eventsapi}

```go
import "github.com/prusa3d/prusa-connect/sdk/eventsapi"
```

Package eventsapi is the contract of an event sink: a plugin that receives the host's events and forwards them wherever it wants.

A plugin implements Processor and calls Register from an init function. The host builds the Processor that the configuration names.

### `Fact` {#eventsapi-fact}

```go
type Fact struct {
    // Origin is what the event came from, such as "device:printer-01".
    Origin event.Origin `json:"origin"`
    // Type is the event type a consumer routes on, such as
    // com.prusa.connect.device.command.requested.
    Type string `json:"type"`
    // Class is the class of the event. Only durable classes reach a sink.
    // Telemetry does not.
    Class event.Class `json:"evclass"`
    // At is the time of the event.
    At time.Time `json:"time"`
    // Sequence and Epoch number the event within its origin. Together with
    // Origin they are the dedup key.
    Sequence uint64 `json:"sequence"`
    Epoch    string `json:"epoch,omitempty"`
    // CausationID is the id of the command that caused this event. Empty when
    // no command caused it. The events of one command share it.
    CausationID string `json:"causationid,omitempty"`
    // Payload is the event's data, unparsed.
    Payload json.RawMessage `json:"data,omitempty"`
}
```

Fact is one durable event of the host, with the fields and the JSON names of its envelope (sdk/event.Envelope). Payload is the event's data, unparsed. sdk/historyapi.Fact has the same content.
