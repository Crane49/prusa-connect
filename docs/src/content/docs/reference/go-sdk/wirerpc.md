`wirerpc` is the session a module runs over the channel the host handed it:
the JSON-RPC control codec, the credit balance, and the loop that runs both.
A child builds a `Conn`, names the methods it answers in `Methods`, and calls
`Serve`. A host builds a `Conn` over the same channel from the other side and
calls methods on it. Both sides use the same type, because both sides call
and answer.

Every child answers the lifecycle set. `MethodInfo` is asked once after the
handshake and answers an `Info`: the module's name, its version, the contract
it was built against, and the methods it serves beyond these two.
`MethodShutdown` asks it to stop. A contract publishes its own methods beside
them, and the typed clients in [`stateapi`](./stateapi.md),
[`busapi`](./busapi.md) and [`deviceapi`](./deviceapi.md) wrap `Conn.Call`,
so a module author rarely writes a raw call. A handler runs on its own
goroutine and returns an `*Error` to choose the code the peer reads; any
other error is reported as `CodeInternal` carrying its text.

```go
package shelf

import (
	"context"
	"io"

	"github.com/prusa3d/prusa-connect/sdk/wirerpc"
)

// serve runs the session over the channel the host handed this process, and
// returns when the host closes it.
func serve(ctx context.Context, channel io.ReadWriteCloser) error {
	// The map is filled before Serve reads it, and it is the same map the
	// session holds, so a handler added here is answered.
	serves := wirerpc.Methods{}

	conn, err := wirerpc.NewConn(channel, wirerpc.Options{Role: wirerpc.RoleChild, Methods: serves})
	if err != nil {
		return err
	}

	serves[wirerpc.MethodInfo] = func(context.Context, wirerpc.Call) (any, error) {
		return wirerpc.Info{Name: "spool-shelf", Version: "0.1.0", Contract: wirerpc.Contract}, nil
	}

	// The answer is written after this returns, and the host closes the
	// channel once it holds it, which is what ends Serve.
	serves[wirerpc.MethodShutdown] = func(context.Context, wirerpc.Call) (any, error) {
		return nil, nil
	}

	return conn.Serve(ctx)
}
```

`Options.Role` is mandatory, because it decides which half of the stream ids
this side opens from. An error message crosses the process boundary and lands
in the peer's log, so it carries no secret and no path the caller has no
business knowing.

## `wirerpc` {#wirerpc}

```go
import "github.com/prusa3d/prusa-connect/sdk/wirerpc"
```

Package wirerpc is the layer above the frame: the JSON-RPC control codec, the credit balance, and the session that runs both over one channel.

A child builds a Conn over the channel its host gave it, names the methods it answers, and calls Serve. A host builds a Conn over the same channel from the other side and calls a method on it.

Stream is an io.ReadWriter. A write waits for the credit the peer granted, and a read grants credit back as it consumes. So a receiver that stops reading stops the sender.

This package does not launch a child process or dial a socket.
