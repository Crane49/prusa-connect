A script is an expression an operator writes in the configuration file. It
maps one event onto zero, one or many messages, and the host publishes them.
`scriptapi` is the environment that expression is evaluated in: the `Event` a
script is handed, and the `Message` it returns. A script author never imports
this package; it is the shape behind the names in their expression.

Every value here is a flat copy with no pointer, no method and no collection,
because a script can read whatever it is given. The `expr` struct tags are
the names a script author writes: `event.kind`, `event.device_id`,
`event.state`. A field the fact does not carry is its zero value, since the
language has no way to ask whether a field was set. A script builds a
message with `msg(endpoint, key, body)`, several with `fan(...)`, and
returns `nil` to drop the event. The endpoint is a name the operator declared
for the instance and never an address, so a script decides what to say and
the operator decides where it goes.

```yaml
resources:
  sink:
    alerts:
      type: script
      runtime: script
      script: |
        event.state == "ERROR"
          ? msg("ops-chat", event.device_id, toJSON({text: event.device_id + " is in ERROR"}))
          : nil
      config:
        endpoints:
          ops-chat: https://chat.example/hooks/ops
```

The same event and message, as the Go values the host builds and reads:

```go
package shape

import "github.com/prusa3d/prusa-connect/sdk/scriptapi"

// stateChanged is what the host hands a script for one printer state change.
// A field the fact does not carry is its zero value, so JobID is "".
var stateChanged = scriptapi.Event{
	Kind:     "printer.state_changed",
	DeviceID: "mk4-01",
	State:    "ERROR",
	Time:     "2026-09-10T10:25:00Z",
}

// alert is what a script returns for it. Endpoint is a name the operator
// declared, and Body is text the script already encoded.
var alert = scriptapi.Message{
	Endpoint: "ops-chat",
	Key:      stateChanged.DeviceID,
	Body:     `{"text":"mk4-01 is in ERROR"}`,
}
```

A script has no assignment and no loop, holds no connection and remembers
nothing between events. Anything that needs one of those is a module.

## `scriptapi` {#scriptapi}

```go
import "github.com/prusa3d/prusa-connect/sdk/scriptapi"
```

Package scriptapi is the environment a script tier adapter is written against: the one event a script is given, and the message it returns.

A script is an expression an operator writes in the configuration file. It maps one event onto zero, one or many messages, and the host publishes them. A script never names a destination address. It names an endpoint the operator declared, a routing key and a body.

Every value here is a copy with no pointer, no method and no collection, so a script cannot reach a live host object. The expr struct tags are the field names a script author writes.

### `Event` {#scriptapi-event}

```go
type Event struct {
    // Kind is what the fact is, such as printer.state_changed. A durable
    // event from the host's bus has its event type here, such as
    // com.prusa.connect.device.job.settled, and none of its payload.
    Kind string `expr:"kind"`
    // DeviceID is the device the fact is about, empty for a fact that is
    // about something else.
    DeviceID string `expr:"device_id"`
    // State is the device's connection or print state, for a state change.
    State string `expr:"state"`
    // Mode is the label mode, for a label change.
    Mode string `expr:"mode"`
    // LabelID is the label, for a label deletion.
    LabelID string `expr:"label_id"`
    // JobID is the job's own identity, for a job update. The host sends no
    // job update, so the three job fields are empty.
    JobID string `expr:"job_id"`
    // JobState is the job's state, for a job update.
    JobState string `expr:"job_state"`
    // JobSource is where the job came from, for a job update.
    JobSource string `expr:"job_source"`
    // Time is when the host read the fact, as RFC 3339 with a UTC offset.
    Time string `expr:"time"`
}
```

Event is one domain fact, flattened for a script to read. A field that does not apply to the fact is the zero value.

### `Message` {#scriptapi-message}

```go
type Message struct {
    // Endpoint is the operator-declared destination this goes to.
    Endpoint string `expr:"endpoint"`
    // Key is the routing key. A broker routes on it, and an HTTP destination
    // sends it as a header.
    Key string `expr:"key"`
    // Body is the payload, already encoded by the script.
    Body string `expr:"body"`
}
```

Message is one thing the host publishes on the script's behalf. Endpoint is a name the operator declared for this instance, never an address.
