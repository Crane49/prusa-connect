A camera driver hands the host the bytes a camera already produces.
`cameraapi` is the contract it implements: which formats the device can emit,
one still image, and a stream of frames the driver has already framed. The
host relays those bytes and reads nothing inside them, so the whole contract
is standard library and every media library stays on the host's side.

The host builds a camera from `ProviderSpec` through the factory given to
`Register`, and calls `Snapshot` for a thumbnail and `Open` for a live view,
often at once. `Printer` on the spec is the authorization key: whoever may
read that printer's telemetry may see this camera. The host reads it from the
operator's declaration, never from the driver. A driver declares its formats
once, and a format it cannot serve is answered with `ErrFormatNotSupported`.
That is the answer and not a fallback: nothing here decodes and re-encodes.
[`cameraapitest`](./cameraapi-cameraapitest.md) is the suite every driver
passes.

```go
package acmecam

import (
	"context"
	"errors"
	"fmt"
	"io"
	"net/http"
	"time"

	"github.com/prusa3d/prusa-connect/sdk/cameraapi"
	"github.com/prusa3d/prusa-connect/sdk/extension"
)

func init() {
	cameraapi.Register("acme-snapshot", extension.Doc{
		Summary:     "Reads stills from a camera that serves one JPEG over HTTP",
		Description: "Fetches snapshot_url on every Snapshot call. It serves no stream.",
		Version:     "0.1.0",
		Contract:    cameraapi.Contract,
		Stability:   extension.StabilityExperimental,
	}, newCamera)
}

// camera serves stills only, so Open is refused for every format.
type camera struct {
	snapshotURL string
	client      *http.Client
}

func newCamera(spec cameraapi.ProviderSpec) (cameraapi.Camera, error) {
	snapshotURL, _ := spec.Config["snapshot_url"].(string)
	if snapshotURL == "" {
		return nil, errors.New("acme-snapshot: snapshot_url is required")
	}

	return &camera{snapshotURL: snapshotURL, client: http.DefaultClient}, nil
}

func (*camera) Formats() []cameraapi.Format {
	return []cameraapi.Format{cameraapi.FormatJPEG}
}

func (c *camera) Snapshot(ctx context.Context) (cameraapi.Snapshot, error) {
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, c.snapshotURL, nil)
	if err != nil {
		return cameraapi.Snapshot{}, err
	}

	resp, err := c.client.Do(req)
	if err != nil {
		return cameraapi.Snapshot{}, err
	}
	defer resp.Body.Close()

	if resp.StatusCode != http.StatusOK {
		return cameraapi.Snapshot{}, fmt.Errorf("acme-snapshot: the camera answered %s", resp.Status)
	}

	image, err := io.ReadAll(resp.Body)
	if err != nil {
		return cameraapi.Snapshot{}, err
	}

	// Taken is when the camera made the frame, so a cached thumbnail stays
	// cached. Last-Modified is that moment when the camera sends one.
	taken, err := http.ParseTime(resp.Header.Get("Last-Modified"))
	if err != nil {
		taken = time.Now()
	}

	return cameraapi.Snapshot{Bytes: image, MediaType: cameraapi.FormatJPEG.MediaType(), Taken: taken}, nil
}

func (*camera) Open(context.Context, cameraapi.Format) (cameraapi.Stream, error) {
	return cameraapi.Stream{}, cameraapi.ErrFormatNotSupported
}

func (*camera) Close() error { return nil }
```

`Taken` is the moment the camera made the frame, and a conditional GET
compares against it. A driver that stamps it with the time of the call turns
every cached thumbnail into a fresh transfer. A stream's `Body` has to return
from a blocked `Read` when the host closes it, or every abandoned viewer is a
goroutine kept.

import "github.com/prusa3d/prusa-connect/sdk/cameraapi"

Package cameraapi is the contract a camera driver implements.

A driver declares the formats its device can emit, returns one still image, and returns a reader of frames it has already framed. The host relays the bytes and never decodes them.

A driver that cannot emit a format returns ErrFormatNotSupported. The host does not convert between formats.

### `Camera` {#cameraapi-camera}

```go
type Camera interface {
    // Formats returns what this camera can emit, in the driver's order of
    // preference. The host refuses a camera that returns none.
    Formats() []Format

    // Snapshot returns the most recent still image. It returns ErrNoFrame
    // when the camera works and has produced nothing yet.
    Snapshot(ctx context.Context) (Snapshot, error)

    // Open starts a stream in one format. It returns ErrFormatNotSupported
    // for a format this camera does not emit. The caller closes the returned
    // Body. Open what the stream needs here and release it when Body is
    // closed. Do not keep a device connection open between streams.
    Open(ctx context.Context, format Format) (Stream, error)

    // Close releases the device. The host calls it once, when the instance
    // stops.
    Close() error
}
```

Camera is what a driver implements. The host may call every method concurrently with every other. A driver that cannot handle that must serialise the calls itself.
