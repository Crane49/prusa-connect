`fractaltest` is for testing Prusa Fractal code. It has a transport that works
in memory, and the conformance suite that every transport must pass. The
protocol and the other packages are introduced on the
[`fractal`](./fractal.md#prusa-fractal) page.

Use the in-memory transport to test an application built on
[`node`](./fractal-node.md) without a network. A `Fabric` connects several
nodes in one process into a tree. `Fabric.Link` makes the link between a node
and one node below it, and `Fabric.Transport` returns the `node.Binding` for
one path. A test can cut a link with `Cut`, bring it back with `Restore`, and
read every message that crossed it with `Watch`. `StateOwner` is a ready
`node.Owner` that keeps property values and runs the methods a test gives it.

Use `RunBindingSuite` when you write a transport. It runs the cases a
transport must pass. A best-effort message is dropped while the link is down.
A durable message waits until the link is back, arrives in order, and is
delivered again when nobody acknowledged it. A durable message with a repeated
id is delivered once. The node above is told when a node below connects and
when it is lost. The transport package implements `TestLink` and passes a
function that builds one.

```go
package site_test

import (
	"encoding/json"
	"iter"
	"slices"
	"testing"
	"testing/synctest"

	"github.com/prusa3d/prusa-connect/sdk/fractal"
	"github.com/prusa3d/prusa-connect/sdk/fractal/fractaltest"
	"github.com/prusa3d/prusa-connect/sdk/fractal/node"
	"github.com/prusa3d/prusa-connect/sdk/fractal/shadow"
)

// only is a node.Admissions with one node id in it.
type only fractal.NodeID

func (o only) Admitted(id fractal.NodeID) bool { return id == fractal.NodeID(o) }

func (o only) Children() iter.Seq[fractal.NodeID] {
	return slices.Values([]fractal.NodeID{fractal.NodeID(o)})
}

// TestAReportReachesTheNodeAbove connects hq and hq/printer-1 in memory and
// reads the printer's state out of hq's shadow.
func TestAReportReachesTheNodeAbove(t *testing.T) {
	synctest.Test(t, func(t *testing.T) {
		key := shadow.Key{Node: "hq/printer-1", Interface: "FDMPrinter1", Instance: "1"}

		fabric := fractaltest.NewFabric(fractaltest.FabricOptions{})

		link, err := fabric.Link("hq", "printer-1")
		if err != nil {
			t.Fatal(err)
		}

		store, err := shadow.New(shadow.Config{Selection: shadow.Selection{Interfaces: []shadow.Key{key}}})
		if err != nil {
			t.Fatal(err)
		}

		hq, err := node.New(node.Config{
			Binding: fabric.Transport("hq"), Path: "hq", Shadow: store, Admissions: only("printer-1"),
		})
		if err != nil {
			t.Fatal(err)
		}

		printer, err := node.New(node.Config{Binding: fabric.Transport("hq/printer-1"), Path: "hq/printer-1"})
		if err != nil {
			t.Fatal(err)
		}

		owner := fractaltest.NewStateOwner(fractal.Props{"nozzleTemp": json.RawMessage(`25.0`)})
		if _, err = printer.Register(node.Instance{Owner: owner, Name: key.Interface, Instance: key.Instance}); err != nil {
			t.Fatal(err)
		}

		for _, engine := range []*node.Node{printer, hq} {
			fabric.Attach(engine.Path(), engine)

			if err = engine.Start(t.Context()); err != nil {
				t.Fatal(err)
			}

			defer func() { _ = engine.Close() }()
		}

		fabric.Start(t.Context())
		defer fabric.Close()

		// When the link comes up, hq asks for a full state report.
		link.Connect(t.Context())
		synctest.Wait()

		if snap, _ := hq.Shadow().Get(key); snap.Status != shadow.StatusOK {
			t.Fatalf("hq reads %s, want OK", snap.Status)
		}

		// A cut link marks the copy stale.
		link.Cut(t.Context())
		synctest.Wait()

		if snap, _ := hq.Shadow().Get(key); snap.Status != shadow.StatusStale {
			t.Fatalf("hq reads %s, want STALE", snap.Status)
		}
	})
}

// TestTheTransportPassesTheSuite is the test a transport package writes. It
// passes its own link factory where this one passes the in-memory one.
func TestTheTransportPassesTheSuite(t *testing.T) {
	fractaltest.RunBindingSuite(t, fractaltest.InMemoryLink)
}
```

The test runs inside `testing/synctest`, so `synctest.Wait` returns when every
message has been handled and the test never sleeps. `examples/fractal-tree`
uses the same `Fabric` for a program with three nodes.

The in-memory transport is for tests and examples. It keeps a durable message
in memory, so nothing survives the end of the process. The transport over NATS
is in the module under `packages/fractal` of this repository, and it runs the
same suite.

Package fractaltest has an in-memory transport for the Prusa Fractal protocol and the conformance suite that every transport must pass.

### The in-memory transport

A Fabric connects several nodes in one process into a tree. Its links follow the delivery rules that sdk/fractal/node states for a transport:

  - messages on one link arrive in the order they were sent
  - a best-effort message sent while the link is down is dropped
  - a durable message sent while the link is down waits, and arrives in order when the link comes back
  - a durable message that the receiver did not acknowledge is delivered again
  - a durable message with an id the link already saw inside the deduplication window is delivered once

A test can cut a link, bring it back, leave a request unacknowledged after the method ran, and move the clock. It needs no network and no sleep.

### The conformance suite

RunBindingSuite tests a transport against those delivery rules. It uses only the node.Binding interface, so a transport over NATS runs the same cases as the in-memory transport of this package. The engine in sdk/fractal/node relies on these rules, so a transport that passes the suite works with it.

### The conformance table

The tests of this package have a table with one row for each MUST sentence of fractal.md. A row names the test that proves the sentence, in this package or in another one. A test of the table fails when a named test does not exist.

### `Engine` {#fractal-fractaltest-engine}

```go
type Engine interface {
    // Deliver receives one message from the transport.
    Deliver(ctx context.Context, in node.Inbound)
    // ChildConnected tells the engine that the link to the node below with
    // this Node ID is up.
    ChildConnected(ctx context.Context, id fractal.NodeID)
    // ChildLost tells the engine that the link to the node below with this
    // Node ID is down.
    ChildLost(ctx context.Context, id fractal.NodeID)
    // ParentConnected tells the engine that the link to the node above is up.
    ParentConnected(ctx context.Context)
    // ParentLost tells the engine that the link to the node above went down
    // after it was up.
    ParentLost(ctx context.Context)
}
```

Engine is the receiving end of a transport: the transport calls it for every message and for every change of a link. A \*node.Node is an Engine. A test that checks only the transport uses a Recorder.

```go

```

Cut takes the link down, calls ChildLost on the engine of the node above and ParentLost on the engine of the node below. A node.Node above then marks as stale the state it keeps for the node below and for every node under that one, and sends a loss message upward. A node.Node below marks its ancestor shadow stale and sends a loss message downward. Stale means the values may be out of date.

Cut calls neither for a link that is already down, or for one that never connected. Only the transport knows whether a link has been up, so the transport applies this rule and not the engine (fractal-nats.md, Where liveness monitoring starts).
