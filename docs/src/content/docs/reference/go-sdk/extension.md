`extension` is the one registration rule every extension point obeys, and
the descriptor every registered entry carries. The contract packages,
`authapi`, `connectorapi`, `storageapi` and the rest, each wrap it, so an
author meets it through their `Register` and reads here what that call holds
them to.

A registry gathers declarations at package initialisation and the host
drains it once. From then on it is sealed, and a late registration is an
error. A qualified name is taken once, and a second registration is refused
rather than replacing the first, which is how a plugin would otherwise
replace a built-in. The namespace half of that name is derived from the
module path of the package that registered, `github.com/acme/mk4` becoming
`com.github.aux.acme.mk4`, and nothing an author passes selects it.

Every entry carries a `Doc`. `Summary`, `Description`, `Version`, `Contract`
and `Stability` are mandatory, a deprecated entry also names `ReplacedBy`,
and the published reference is generated from these fields. `Version` is
`MAJOR.MINOR.PATCH`, and `CompatibleWith` is how a host refuses an entry
built against a contract it does not serve, at registration and not at first
use.

```go
package acmehook

import (
	"github.com/prusa3d/prusa-connect/sdk/event"
	"github.com/prusa3d/prusa-connect/sdk/eventsapi"
	"github.com/prusa3d/prusa-connect/sdk/extension"
)

// doc is what the published reference says about this sink, and what the
// host refuses the registration without.
var doc = extension.Doc{
	Summary:     "Posts every durable event to one URL",
	Description: "Sends each fact as JSON to url. It keeps nothing and retries nothing.",
	Version:     "0.1.0",
	Contract:    eventsapi.Contract,
	Stability:   extension.StabilityExperimental,
	Options: []extension.Option{
		{Key: "url", Type: extension.OptionURL, Required: true, Summary: "Where each event is posted"},
		{Key: "timeout", Type: extension.OptionDuration, Default: "5s", Summary: "How long one post may take"},
	},
	Consumes: []event.Class{event.ClassState},
}

// namespace answers what an operator writes to select a type this module
// registers, before the module exists.
func namespace() (extension.Namespace, error) {
	return extension.NamespaceOf("github.com/acme/spool-hook")
}
```

A missing mandatory field is a refused registration, because an empty string
would ship as documentation. `NamespaceOf` answers, before a module exists,
whether its path registers at all.

## `extension` {#extension}

```go
import "github.com/prusa3d/prusa-connect/sdk/extension"
```

Package extension is the registration rule of every extension point, and the descriptor of every registered entry.

A registry gathers declarations at package initialisation and the host drains it once. After that a registration is an error. A qualified name may be registered once, and a second registration is refused.

A name is qualified by a namespace derived from the module of the package that registered it. An author cannot choose it. Only the main module of a build has the core namespace.

Doc says which descriptor fields are mandatory.
