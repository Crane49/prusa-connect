`transferapi` is the contract for reading back the record of a file this host
moved from one of its storages onto a device. It publishes no way to write
one. The core puts the two durable transfer frames of [`event`](./event.md)
on the bus, and a history adapter stores them as facts like any other. An
adapter that wants one row per transfer folds them into it.

`Records` is an ability and not a requirement. A history adapter that keeps
the projection implements `Transfers`; one that does not simply leaves it
out. The host probes with `Of`, a type assertion, so an adapter cannot claim
a table it does not have, and a caller reads `ErrNoRecords` rather than an
empty page. "This build stores no transfer history" and "this device has
moved no files" are different answers. A `Query` names a device or every
device, a limit, and whether to answer running rows only, which is what the
restart sweep asks.

```go
package acmehistory

import (
	"context"
	"sync"

	"github.com/prusa3d/prusa-connect/sdk/transferapi"
)

// transfers is the projection a history adapter keeps: one row per transfer,
// folded from the started and settled frames as they are appended.
type transfers struct {
	mu   sync.Mutex
	rows []transferapi.Record
}

// Of finds this through a type assertion, so implementing Transfers is the
// whole declaration.
var _ transferapi.Records = (*transfers)(nil)

// Transfers answers newest first, narrowed by the query.
func (t *transfers) Transfers(_ context.Context, query transferapi.Query) ([]transferapi.Record, error) {
	t.mu.Lock()
	defer t.mu.Unlock()

	limit := query.Limit
	if limit <= 0 {
		limit = 50
	}

	var page []transferapi.Record

	for i := len(t.rows) - 1; i >= 0 && len(page) < limit; i-- {
		row := t.rows[i]

		if query.Device != "" && row.Device != query.Device {
			continue
		}

		if query.RunningOnly && !row.Running() {
			continue
		}

		page = append(page, row)
	}

	return page, nil
}
```

`Warning` is carried by the live record and by the answer to the request that
ran the transfer. The durable frames do not carry it, so a record read back
from a store holds none. `StateQueued` and `StateSending` are read from the
live register only.

Package transferapi is the contract for reading back the record of a file this host moved from one of its storages onto a device.

This package has no way to write a record. A history adapter builds the records from the transfer events of sdk/event. Records is optional: an adapter that keeps no such records does not implement it.
