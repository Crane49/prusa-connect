`schema` describes a Prusa Fractal interface as a JSON file, and checks
property values, method parameters and method results against that file. The
protocol and the other packages are introduced on the
[`fractal`](./fractal.md#prusa-fractal) page.

Use this package when your node owns an interface and you want wrong values
refused before your code sees them. One file describes one interface: its
name, its properties with a type and an access mode, its methods with their
parameters, and the enumerations they use. Adding a property is an edit to the
file, and no Go code changes. The interfaces of a Prusa printer are already
written this way in [`prusa`](./fractal-prusa.md).

`Load` reads the files from any `fs.FS` and returns a `Registry`. A
`Definition` from the registry has a check for each message. `ValidateDES`
checks a property change request and `ValidateParams` checks a method call.
`ValidateREP` checks a state report and `ValidateResult` checks a method
result. Pass the definition to [`node`](./fractal-node.md) as
`Instance.Definition`, and the node runs the first two checks itself.

```json
{
  "interface": "Chamber1",
  "exposure": "upward",
  "properties": [
    { "name": "tempChamber", "type": "float", "access": "ro", "nullable": true },
    { "name": "ledIntensity", "type": "int", "access": "rw" }
  ],
  "methods": [
    { "name": "SetFan", "params": [{ "name": "percent", "type": "int" }], "returns": "bool" }
  ]
}
```

```go
package chamber

import (
	"embed"
	"encoding/json"
	"errors"
	"fmt"

	"github.com/prusa3d/prusa-connect/sdk/fractal"
	"github.com/prusa3d/prusa-connect/sdk/fractal/schema"
)

// files has chamber.json, the file above.
//
//go:embed chamber.json
var files embed.FS

func run() error {
	registry, err := schema.Load(files)
	if err != nil {
		return err // a *schema.LoadError names the file and the place in it
	}

	chamber, ok := registry.Definition("Chamber1")
	if !ok {
		return errors.New("chamber.json describes no Chamber1")
	}

	// A request to change a property. ledIntensity is writable and 80 is an int.
	err = chamber.ValidateDES(fractal.Props{"ledIntensity": schema.RawInt(80)})
	fmt.Println(err) // <nil>

	// tempChamber is read-only, so the whole request is refused.
	err = chamber.ValidateDES(fractal.Props{"tempChamber": json.RawMessage(`30.5`)})

	var fault *schema.PropertyError
	fmt.Println(errors.As(err, &fault)) // true

	// The parameters of a method call, in the order the file lists them.
	err = chamber.ValidateParams("SetFan", []json.RawMessage{json.RawMessage(`"fast"`)})
	fmt.Println(err != nil) // true: "fast" is not an int

	return nil
}
```

The types are `string`, `int`, `float`, `bool` and the enumerations a file
declares. There are no nested objects and no arrays. An `int` is a JSON number
with no fraction and no exponent, so `1.0` is refused. `null` passes only for
a nullable property or an optional parameter. A value stays as
`json.RawMessage`: a check reads the bytes and builds no Go value.
`ReadInt`, `ReadFloat`, `ReadString` and `ReadBool` turn a checked value into
a Go value, and `RawInt` and the functions beside it go the other way.

A `Registry` cannot change after `Load` returns, so any number of goroutines
can read it. This package includes no interface of its own, and it sends and
receives nothing.

## `fractal/schema` {#fractal-schema}

Package schema loads the definition of a Fractal interface from a JSON file and validates messages against it. Load and Builder.Build return a Registry that is never written again, so it is safe for concurrent reads.

One file describes one interface and may declare enumerations. An enumeration declared in any file can be used in every file.

	{
	  "interface": "Chamber1",
	  "exposure": "upward",
	  "enums": [
	    { "name": "NozzleType", "values": ["BRASS", "HARDENED", "STAINLESS"] }
	  ],
	  "properties": [
	    { "name": "tempChamber", "type": "float", "access": "ro", "nullable": true },
	    { "name": "ledIntensity", "type": "int", "access": "rw" }
	  ],
	  "methods": [
	    {
	      "name": "SetNozzle",
	      "params": [{ "name": "nozzleType", "type": "NozzleType" }],
	      "returns": "bool"
	    }
	  ]
	}

"exposure" is "upward", "downward" or "both". "access" is "ro" or "rw". A type is "string", "int", "float", "bool" or a declared enumeration. "nullable" and "optional" default to false. A method with no "returns" returns nothing. An RPC sends parameters in the order the file lists them.

The values each type accepts:

  - "int": a JSON number with no fraction and no exponent that fits in a signed 64-bit integer. 1 is valid, 1.0 and 1e3 are not.
  - "float": any JSON number that fits in a 64-bit float.
  - An enumeration: a JSON string that the enumeration lists.
  - null: only for a nullable property and for an optional parameter.
  - The result of a method that declares a return type is never null.
