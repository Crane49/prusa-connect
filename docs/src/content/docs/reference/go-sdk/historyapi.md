The core emits and never remembers. A history provider is the optional store
that keeps measurements and events after the hub has forgotten them, and
`historyapi` is the contract it implements. A deployment with none has no
past, and every feature that needs one says so.

An event's class decides which half of the contract it reaches, and `VerbOf`
is that table: telemetry goes to `AppendSamples`, everything else to
`AppendFacts`. Both are called per batch by the host and never per frame, so
a provider is never on the path a reading takes to a browser. `Caps` is the
authority on what a provider serves. A method whose bit is clear answers
`ErrUnsupported`, and a caller that read the bits never calls it. A query the
provider serves but will not answer truthfully, a raw window whose rows have
expired for instance, answers `RefuseQuery` with the coarsest step it can
still give. `Refs` on every query is already reduced to what the caller may
read; a provider never sees a principal.

Time is kept to `Precision`, one microsecond, and `Truncate` is the one way
to reach it. A `Sample` carries a number or a word, and `Check` refuses one
that carries both.

```go
package acmehistory

import (
	"context"
	"database/sql"
	"time"

	"github.com/prusa3d/prusa-connect/sdk/historyapi"
)

// store keeps samples and facts in SQL. Caps says which halves it serves,
// and a method whose bit is clear answers ErrUnsupported.
type store struct{ db *sql.DB }

func (*store) Caps() historyapi.Caps {
	return historyapi.CapSamples | historyapi.CapFacts | historyapi.CapRetention
}

// AppendSamples refuses a malformed batch whole rather than storing half of
// it. The rows are keyed by ref, metric and historyapi.Truncate(at).
func (s *store) AppendSamples(ctx context.Context, samples []historyapi.Sample) error {
	for _, sample := range samples {
		if err := sample.Check(); err != nil {
			return err
		}
	}

	return s.insertSamples(ctx, samples)
}

// QuerySamples answers raw rows. This store carries no CapAggregate, so a
// step is refused with the reason rather than answered approximately.
func (s *store) QuerySamples(ctx context.Context, query historyapi.SampleQuery) (historyapi.SampleResult, error) {
	if query.Step != 0 {
		return historyapi.SampleResult{}, historyapi.RefuseQuery(
			"this store keeps raw samples and answers no step", 0, time.Time{})
	}

	return s.selectSamples(ctx, query)
}

func (*store) QueryCommands(context.Context, historyapi.CommandQuery) (historyapi.CommandResult, error) {
	return historyapi.CommandResult{}, historyapi.ErrUnsupported
}

// Retention declares what the store's own sweep keeps: raw rows for 30 days.
func (*store) Retention() []historyapi.Resolution {
	return []historyapi.Resolution{{Step: 0, Keeps: 30 * 24 * time.Hour}}
}
```

The rest of `Provider` is the store's own SQL and is not shown. A provider
truncates an instant towards the epoch and never rounds, so two adjacent
samples cannot share a key.

## `historyapi` {#historyapi}

```go
import "github.com/prusa3d/prusa-connect/sdk/historyapi"
```

Package historyapi is the contract a history provider implements: the store that keeps metrics and events. A provider is optional, and the core never waits for one.

The class of an event decides where it is stored. Telemetry goes to AppendSamples and every other class goes to AppendFacts. See VerbOf.

A metric name is the state path the value was reported under.

A provider declares what it serves in Caps. A method whose bit is clear returns ErrUnsupported.

```go
type Command struct {
    // ID is the command id, created by the host.
    ID string
    // Ref is the origin the command was issued against.
    Ref event.Origin
    // Verb is the capability key that was invoked.
    Verb string
    // Key is the caller's idempotency key, empty when none was sent.
    Key string

    Authorized time.Time
```

### `Provider` {#historyapi-provider}

```go
type Provider interface {
    // Caps is what this provider serves. It must not change while the
    // provider runs.
    Caps() Caps
    // AppendSamples stores a batch of measurements. Two equal measurements at
    // different instants are two samples.
    AppendSamples(ctx context.Context, samples []Sample) error
    // AppendFacts stores a batch of events. It is idempotent on the dedup key
    // of Fact.
    AppendFacts(ctx context.Context, facts []Fact) error
    // QuerySamples returns the samples of a time range.
    QuerySamples(ctx context.Context, query SampleQuery) (SampleResult, error)
    // QueryFacts returns the events of a time range.
    QueryFacts(ctx context.Context, query FactQuery) (FactResult, error)
    // QueryCommands returns folded command rows. A provider without
    // CapCommands returns ErrUnsupported.
    QueryCommands(ctx context.Context, query CommandQuery) (CommandResult, error)
    // Retention is what this provider keeps, sorted coarsest last. Nil means
    // it keeps everything. It must not change while the provider runs.
    Retention() []Resolution
}
```

Provider is the contract of a history store. The host calls it per batch and per query, never per event.
