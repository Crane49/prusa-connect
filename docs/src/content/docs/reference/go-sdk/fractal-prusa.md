`prusa` has the interfaces of a Prusa printer as data files that
[`schema`](./fractal-schema.md) loads. The Prusa Fractal specification defines
those interfaces, and these files are the same definitions in JSON. The
protocol and the other packages are introduced on the
[`fractal`](./fractal.md#prusa-fractal) page.

Use this package when your node represents a Prusa printer, or calls one, and
you want the names and types from the specification without typing them
again. The package exports one value, `Files`, an embedded filesystem. There
is one file for each interface: `Device1`, `UpgradableDevice1`, `Controller1`,
`Printer1`, `PrintJob1`, `FDMPrinter1`, `FDMPrinterHead1`, `FDMPrintJob1`,
`FilamentSlot1`, `Chamber1` and `SLAPrinter1`. The enumerations that more than
one interface uses, such as `PrinterState` and `FDMMaterial`, are together in
`enums.json`.

```go
package printers

import (
	"encoding/json"
	"errors"
	"fmt"

	"github.com/prusa3d/prusa-connect/sdk/fractal/prusa"
	"github.com/prusa3d/prusa-connect/sdk/fractal/schema"
)

func run() error {
	registry, err := schema.Load(prusa.Files)
	if err != nil {
		return err
	}

	printer, ok := registry.Definition("Printer1")
	if !ok {
		return errors.New("the files describe no Printer1")
	}

	for property := range printer.Properties() {
		fmt.Println(property.Name()) // state, then speed
	}

	// PrintFile takes one string, the address of the file.
	url := schema.RawString("https://files.example/benchy.bgcode")

	return printer.ValidateParams("PrintFile", []json.RawMessage{url})
}
```

Pass a definition to [`node`](./fractal-node.md) as `Instance.Definition`, and
the node checks every property change request and every method call against
it.

This package has no Go code beyond `Files`. It does not talk to a printer and
it implements no method: the application behind the interface does that, as a
`node.Owner`. For an interface of your own, write a file in the same format.
A `schema.Builder` takes these files and yours with one `AddFS` call each, and
`Build` returns a registry with all of them.

## `fractal/prusa` {#fractal-prusa}

```go
import "github.com/prusa3d/prusa-connect/sdk/fractal/prusa"
```

Package prusa embeds the definition files of the Prusa printer interfaces, in the format that package sdk/fractal/schema loads.

	registry, err := schema.Load(prusa.Files)

To add a property to an interface, add one line to its JSON file. enums.json defines every enumeration.

### `Files` {#fractal-prusa-files}

```go
var Files embed.FS
```

Files is the embedded filesystem with every definition file, in its root directory. Pass it to schema.Load.
