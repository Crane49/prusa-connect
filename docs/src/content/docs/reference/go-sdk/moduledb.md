`moduledb` opens the database the operator granted a module and applies the
module's migrations. A module imports it when its manifest asks for
`needs.database: true` ([ADR-20261021-bqc](../../../../../decisions/20261021-bqc-a-module-may-keep-its-data-in-a-database-of-its-own.md)).

The module calls `Open` inside its `plugin.configure` handler. So the schema
is applied before the module reports ready, and a migration that fails
refuses the start. Every migration of one upgrade runs in one transaction, so
a failed upgrade leaves the database as it was. The handler answers the
report, and the host shows the schema version on the resources listing.

```go
package main

import (
	"context"
	"database/sql"
	"embed"

	_ "github.com/lib/pq"
	_ "modernc.org/sqlite"

	"github.com/prusa3d/prusa-connect/sdk/moduledb"
	"github.com/prusa3d/prusa-connect/sdk/wirerpc"
)

//go:embed migrations/sqlite/*.sql migrations/postgres/*.sql
var migrations embed.FS

var schema = moduledb.Schema{
	Migrations: migrations,
	Steps:      []moduledb.Step{{Version: 3, Name: "count_words", Up: countWords}},
}

var db *sql.DB

func configure(ctx context.Context, _ struct{}, grants wirerpc.Grants) (wirerpc.Configured, error) {
	opened, report, err := moduledb.Open(ctx, *grants.Database, schema)
	if err != nil {
		return wirerpc.Configured{}, err
	}

	db = opened

	return wirerpc.Configured{Database: report.State()}, nil
}

// Registered as wirerpc.MethodConfigure: wirerpc.ConfigureReporting(configure).
```

`examples/database-module` is a whole module built this way, with a step
that counts the words of the notes kept before its column existed.

## `moduledb` {#moduledb}

```go
import "github.com/prusa3d/prusa-connect/sdk/moduledb"
```

Package moduledb opens a module's own database and migrates it.

The host sends a wirerpc.DatabaseGrant in plugin.configure. Call Open with it inside the plugin.configure handler and answer Report.State.

A module embeds migrations/sqlite/\*.sql and migrations/postgres/\*.sql. Name a new file by its UTC date and time, such as 20261027T093015\_note\_tags.sql. One call applies every unrecorded migration in one transaction. An applied file must not change, and there are no down migrations.

This package imports only the standard library, so the module registers the database drivers, such as modernc.org/sqlite and github.com/lib/pq.

#### `Migrate` {#moduledb-migrate}

```go
func Migrate(ctx context.Context, db *sql.DB, engine wirerpc.DatabaseEngine, schema Schema) (Report, error)
```

Migrate applies every migration of schema the database has not recorded, in one transaction, and raises its compat floor. On a failure the database stays as it was. An unrecorded migration is applied even when it sorts before a recorded one. A database lock keeps two processes from migrating at once.

#### `Open` {#moduledb-open}


Open opens the granted database, migrates it and returns the handle with a report of what the migration did. The caller closes the handle. On a failure the database stays as it was. A SQLite handle has one connection, and a module that reads a lot may raise that with SetMaxOpenConns.

### `Schema` {#moduledb-schema}

```go
type Schema struct {
    // Migrations is migrations/sqlite/*.sql and migrations/postgres/*.sql,
    // usually an embed.FS. See MigrationName for the names and the order
    // they are applied in.
    Migrations fs.FS
    // Steps are the migrations written in Go, ordered among the files by
    // their date or version. A step runs after the file of its own date or
    // version, in the same transaction.
    Steps []Step
    // Compat is the oldest numbered schema version that may open a database
    // this release migrated. Zero sets no floor. A schema of dated
    // migrations sets Floor instead.
    Compat int
    // Floor names the newest migration an older release cannot work with,
    // such as one that drops a column. A release that does not ship it
    // refuses the database. It must be a migration this release ships.
    Floor string
    // SQLiteDriver is the database/sql driver name for SQLite. Empty is
    // DefaultSQLiteDriver.
    SQLiteDriver string
    // PostgresDriver is the database/sql driver name for Postgres. Empty is
    // DefaultPostgresDriver.
    PostgresDriver string
}
```

Schema is a module's migrations, its compat floor and the drivers it registered.

### `Step` {#moduledb-step}

```go
type Step struct {
    // Stamp orders the step among dated files, in StampLayout, such as
    // 20261027T093015. The step is recorded in the ledger as
    // <stamp>_<name>.go.
    Stamp string
    // Version orders the step among numbered files, whose version is the
    // number their name starts with. The step is recorded in the ledger as
    // <version>_<name>.go, the version written with four digits.
    Version int
    // Name is lower case letters, digits and underscores. Renaming a step
    // that was applied is refused, as renaming a file is.
    Name string
    // Up changes the data. engine says which SQL dialect tx speaks. An error
    // rolls back the whole upgrade.
    Up func(ctx context.Context, tx Tx, engine wirerpc.DatabaseEngine) error
}
```

Step is a migration written in Go, for a change SQL cannot express. It runs in the same transaction as every other migration of the upgrade, after the SQL file of the same date or version. A step sets Stamp or Version, never both. A new step sets Stamp.
