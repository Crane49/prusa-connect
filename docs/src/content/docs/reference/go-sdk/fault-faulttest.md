`faulttest` closes the first of the error code gates: a code the server
returns that the registry does not document. A handler test hands the bytes it
already asserts on to `AssertBodyRegistered`. It finds every `code` member in
the document and fails the test for any the registry does not know. It reads
whatever the surface answers with: a problem document, an event's
`data.error`, a command result, or a list of any of those. A body carrying no
code passes, because the gate is about codes that are returned and not about
which responses must carry one.

```go
package acmeshelf

import (
	"encoding/json"
	"net/http"
	"net/http/httptest"
	"testing"

	"github.com/prusa3d/prusa-connect/sdk/fault"
	"github.com/prusa3d/prusa-connect/sdk/fault/faulttest"
)

func TestEveryCodeTheHandlerAnswersIsRegistered(t *testing.T) {
	handler := http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		f := SpoolEmpty.New("slot 3 reports 0 g").With(fault.IntParam("slot", 3))

		w.Header().Set("Content-Type", "application/problem+json")
		w.WriteHeader(f.Status())
		_ = json.NewEncoder(w).Encode(f.ProblemJSON(r.URL.Path))
	})

	rec := httptest.NewRecorder()
	handler.ServeHTTP(rec, httptest.NewRequest(http.MethodPost, "/slots/3/feed", nil))

	// Every code member in the body has to be one the registry documents.
	faulttest.AssertBodyRegistered(t, fault.Global(), rec.Body.Bytes())
}
```

Passing a nil registry means the global one, which is what a server binary
answers from.

### `ErrMalformedCode` {#fault-faulttest-errmalformedcode}

```go
var ErrMalformedCode = errors.New("faulttest: malformed code member")
```

ErrMalformedCode reports a code member whose text is not a domain/REASON pair. A response carrying one is broken in the same way an unregistered code is: no client can branch on it.

### `AssertBodyRegistered` {#fault-faulttest-assertbodyregistered}

AssertBodyRegistered fails tb unless every error code in body is registered. A body carrying no code passes: this gate is about codes that are returned, not about which responses must carry one.

### `Codes` {#fault-faulttest-codes}

```go
func Codes(body []byte) ([]fault.Code, error)
```

Codes returns every error code the document carries, in the order they appear and without repeats. A code member that is not a string is left alone, because a member of that name can mean something else; a string that is not a valid code reports ErrMalformedCode.
