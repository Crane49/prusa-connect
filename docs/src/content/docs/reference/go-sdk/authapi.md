An identity provider is how a person proves who they are to this server: a
username and password, a redirect to an issuer, or a bearer token another
issuer signed. `authapi` is the contract such a provider implements. It is
compiled into a build and registered from an `init` function.

The host calls the provider. It builds one from `ProviderSpec` through the
factory given to `Register`, reads `Capabilities` to know which login forms
to offer, and calls the flow a person chose. The provider answers with an
`Identity`: a subject, a display name and roles. The host owns everything
after that. It mints the session and the tokens, keeps the local account
table, and pairs a bearer subject to a principal. A provider never sees any
of it, and the factory signature is what keeps that true: it carries no host
service to hold.

A provider declares the flows it serves in `Capabilities` and answers
`ErrUnsupportedFlow` for the rest. One that advertises `Bearer` also
implements `TokenVerifier`, which checks a token offline against keys it
already holds; [`oidctoken`](./authapi-oidctoken.md) has that half written
out. [`authapitest`](./authapi-authapitest.md) is the suite every provider
passes.

```go
package acmesso

import (
	"context"
	"net/url"

	"github.com/prusa3d/prusa-connect/sdk/authapi"
	"github.com/prusa3d/prusa-connect/sdk/extension"
)

// directory is what a password is checked against. The bind behind it is the
// provider's own and is not shown here.
type directory interface {
	Bind(ctx context.Context, username, password string) (roles []string, ok bool)
}

func init() {
	authapi.Register("acme-sso", extension.Doc{
		Summary:     "Signs people in against the Acme directory",
		Description: "Checks a username and password with one bind against the directory. It serves no redirect flow.",
		Version:     "0.1.0",
		Contract:    authapi.Contract,
		Stability:   extension.StabilityExperimental,
	}, func(spec authapi.ProviderSpec) (authapi.IdentityProvider, error) {
		dir, err := openDirectory(spec.Config)
		if err != nil {
			return nil, err
		}

		return &provider{directory: dir}, nil
	})
}

type provider struct{ directory directory }

func (*provider) Name() string { return "acme-sso" }

func (*provider) Capabilities() authapi.Capabilities {
	return authapi.Capabilities{Credentials: true}
}

func (p *provider) VerifyCredentials(ctx context.Context, username, password string) (authapi.Identity, error) {
	roles, ok := p.directory.Bind(ctx, username, password)
	if !ok {
		return authapi.Identity{}, authapi.ErrInvalidCredentials
	}

	return authapi.Identity{Subject: username, DisplayName: username, Roles: roles}, nil
}

// The redirect flow and revalidation are not advertised, so each answers
// ErrUnsupportedFlow.
func (*provider) BeginLogin(context.Context, string, string) (string, string, error) {
	return "", "", authapi.ErrUnsupportedFlow
}

func (*provider) CompleteLogin(context.Context, url.Values, string) (authapi.Identity, error) {
	return authapi.Identity{}, authapi.ErrUnsupportedFlow
}

func (*provider) RefreshIdentity(context.Context, string) (authapi.Identity, error) {
	return authapi.Identity{}, authapi.ErrUnsupportedFlow
}
```

`openDirectory` is the provider's own and is not shown. Answer
`ErrInvalidCredentials` for a bad pair and nothing more specific: a refusal
that says which half was wrong tells an attacker which half was right.

## `authapi` {#authapi}

```go
import "github.com/prusa3d/prusa-connect/sdk/authapi"
```

Package authapi is the contract for identity providers. A separate Go module implements IdentityProvider and registers itself from an init(). Registration follows sdk/extension.

The scope is human authentication: people using the web UI, API, MQTT or SSE. Printer authentication belongs to a connector.

The host owns token issuance and validation. A provider only proves who the caller is and returns an Identity. It never sees the token store or the local user database.

### `Capabilities` {#authapi-capabilities}

```go
type Capabilities struct {
    // Credentials is true when the provider supports VerifyCredentials
    // (username/password, basic-auth, API key).
    Credentials bool `json:"credentials"`
    // Redirect is true when the provider supports the BeginLogin/CompleteLogin
    // redirect flow (OIDC / OAuth / SAML).

}
```

Capabilities says which authentication flows a provider supports.

### `IdentityProvider` {#authapi-identityprovider}

```go
type IdentityProvider interface {
    // Name is the provider's unique identifier / type (e.g. "local", "oidc").
    Name() string
    // Capabilities reports which flows this provider supports.
    Capabilities() Capabilities

    // VerifyCredentials authenticates a username/password (or equivalent).
    // Returns ErrInvalidCredentials on a bad pair, ErrUnsupportedFlow if the
    // provider does not support credential auth.
    VerifyCredentials(ctx context.Context, username, password string) (Identity, error)

    // BeginLogin starts a redirect flow. The host generates the CSRF `state`.
    // The provider embeds it in the authorize request, as `state` for
    // OAuth/OIDC or `RelayState` for SAML. It returns the URL to send the
    // browser to and an opaque providerState, such as a PKCE code_verifier.
    // The host stores providerState and passes it unchanged to CompleteLogin.
    BeginLogin(ctx context.Context, redirectURI, state string) (authorizeURL, providerState string, err error)

    // CompleteLogin finishes a redirect flow from the provider callback. params
    // is the union of the callback's query and form values, so it serves an
    // OAuth/OIDC GET and a SAML HTTP-POST. providerState is the value
    // BeginLogin returned for this state.
    CompleteLogin(ctx context.Context, params url.Values, providerState string) (Identity, error)

    // RefreshIdentity re-checks an authenticated subject at the provider and
    // returns the current Identity. It returns ErrIdentityRevoked when the
    // subject is gone or disabled, and ErrUnsupportedFlow when the provider
    // does not advertise Revalidation.
    RefreshIdentity(ctx context.Context, subject string) (Identity, error)
}
```

IdentityProvider authenticates a human and returns an Identity. A provider implements the flows it advertises in Capabilities. For any other flow it must return ErrUnsupportedFlow.
