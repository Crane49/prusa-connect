`diagnosticsapi` lets a module add text files to the diagnostics bundle an
admin downloads from Settings, Diagnostics. A module that keeps evidence of a
fault imports it, such as the printer logs extension, which adds the lines a
printer logged before something went wrong.

The module names `diagnostics.collect` in `Info.Serves` and answers it with
`Serve`. The host asks only when the admin ticks the files from extensions.
It asks page by page, because one wire frame is at most 1 MiB. A page holds at
most 512 files. The host takes at most 8 MiB, 1024 files and 64 pages from one
module, and gives it at most one minute. So put what matters most first: for a
log, the newest lines.

The host scrubs every line before it writes it under `modules/<kind>.<name>/`
in the zip, as it scrubs its own logs. A part of a file name that holds an
address or a MAC is replaced with a hash. A module still leaves out anything it
knows to be secret. The rules are ADR-20261019-nrq.

## `diagnosticsapi` {#diagnosticsapi}

```go
import "github.com/prusa3d/prusa-connect/sdk/diagnosticsapi"
```

Package diagnosticsapi is how a module adds files to the diagnostics bundle an admin downloads from Settings.

A module names MethodCollect in its Info.Serves and answers it with Serve. The host asks page by page and stops at its own limit, so answer with what matters most first. For a log that is the newest lines.

The host scrubs every line before it writes it: addresses, MACs, tokens and paths are replaced. A module still leaves out what it knows to be secret.

### `Serve` {#diagnosticsapi-serve}


Serve builds the handler a module answers MethodCollect with. collect is called once per page with the cursor the host sent back. Each page is validated before it is sent.

### `ValidName` {#diagnosticsapi-validname}

```go
func ValidName(name string) bool
```

ValidName reports whether name may name a file: a relative path of at most MaxNameBytes letters, digits, '.', '\_', '-' and '/', with no empty, "." or ".." segment. A segment that is not valid on Windows is refused too: a device name such as "con" or "aux.log", and a segment that ends with '.'.

### `File` {#diagnosticsapi-file}

```go
type File struct {
    // Name is a relative path that passes ValidName, such as
    // "syslog/printer-1.log". The host replaces a part that names an address
    // or a secret with a hash. It refuses a name that differs from an earlier
    // one only in case, and one that uses an earlier file as a folder.
    Name string `json:"name"`
    // Text is UTF-8 text. A log is one line per entry.
    Text string `json:"text"`
}
```

File is text for one file in the bundle. Text with the same Name on a later page is appended to the same file. A file whose text is empty adds nothing, and the host writes no file for it.
