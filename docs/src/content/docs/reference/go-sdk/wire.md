`wire` is the frame an out-of-process extension and this host exchange, and
the handshake line that opens the connection. One frame is a payload length,
a stream id, a kind and a payload. A control frame carries one JSON-RPC 2.0
object, a data frame carries raw bytes, and the three remaining kinds end a
stream, reset it and grant credit on it.

The published specification is the contract, and this package is one
implementation of it. A module written in Go builds on
[`wirerpc`](./wirerpc.md), which runs the session above these frames, and
touches this package for the handshake alone. The child writes
`Handshake.Line()` to standard output before its first frame. A host reads
that line with `ParseHandshake` and settles the minor with `Negotiate`.
`Reader` and `Writer` are for a program that speaks the frames itself.

```go
package framing

import (
	"bytes"
	"errors"
	"fmt"
	"io"

	"github.com/prusa3d/prusa-connect/sdk/wire"
)

// roundTrip writes one call on stream 2 as a child would, then reads the
// bytes back as a host would.
func roundTrip() error {
	var channel bytes.Buffer

	w := wire.NewWriter(&channel, 0)

	call := []byte(`{"jsonrpc":"2.0","id":1,"method":"plugin.info"}`)
	if err := w.Write(wire.Control(2, call)); err != nil {
		return err
	}

	if err := w.Write(wire.End(2)); err != nil {
		return err
	}

	r := wire.NewReader(&channel, 0)

	for {
		frame, err := r.Next()
		if errors.Is(err, io.EOF) {
			return nil
		}

		if err != nil {
			return err
		}

		// The payload is valid until the next call to Next. Clone keeps it.
		kept := frame.Clone()
		fmt.Printf("stream %d %s, %d bytes\n", kept.Stream, kept.Kind, len(kept.Payload))
	}
}

// accept reads the line a child wrote and answers the minor both sides speak.
func accept(line string) (uint32, error) {
	child, err := wire.ParseHandshake(line)
	if err != nil {
		return 0, err
	}

	host := wire.Handshake{Protocol: wire.ProtocolMajor, MinMinor: wire.MinMinor, MaxMinor: wire.MaxMinor}

	return wire.Negotiate(host, child)
}
```

A `Reader`'s refusal is final. The bytes after a header it would not accept
belong to a frame nobody parsed, so every later call answers
`ErrDesynchronised` and the caller closes the connection. A `Writer` is used
by one goroutine at a time, and a frame's payload is valid until the next
call to `Next`.

Package wire is the frame an out-of-process extension and the host exchange, and the handshake line that opens the connection.

One frame has a payload length, a stream id, a kind and a payload. Control frames contain one JSON-RPC 2.0 object, data frames contain raw bytes, and the three remaining kinds end a stream, reset it and grant credit on it.

The published wire protocol specification is the contract. This package is one implementation of it.

This package frames bytes. It does not launch a child, dial a socket, encode a JSON-RPC object, or account for credit. See sdk/wirerpc.
