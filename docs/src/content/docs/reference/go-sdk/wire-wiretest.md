`wiretest` holds the conformance vectors for the plugin wire protocol, and
nothing else. Every vector states bytes a person wrote down, not bytes a
codec produced, because a vector a codec generated proves only that the codec
agrees with itself. `Frames`, `Handshakes`, `Negotiations` and `Refusals` are
the four sets. `Reasons` names why a refused vector is refused, in words that
carry no Go, so an implementation in another language reads them from the
published JSON.

A test of a frame codec, in Go or elsewhere, encodes each frame vector and
compares bytes, then decodes each and compares fields. It feeds each refusal
vector to its reader and checks the reason it gives.

```go
package framing

import (
	"bytes"
	"testing"

	"github.com/prusa3d/prusa-connect/sdk/wire"
	"github.com/prusa3d/prusa-connect/sdk/wire/wiretest"
)

// TestFramesMatchTheVectors holds a writer to the bytes a person wrote down.
// A codec checked only against itself proves that it agrees with itself.
func TestFramesMatchTheVectors(t *testing.T) {
	for _, vector := range wiretest.Frames() {
		t.Run(vector.Name, func(t *testing.T) {
			want, err := vector.Bytes()
			if err != nil {
				t.Fatal(err)
			}

			payload, err := vector.Payload()
			if err != nil {
				t.Fatal(err)
			}

			var got bytes.Buffer

			frame := wire.Frame{Stream: vector.Stream, Kind: vector.Kind, Payload: payload}
			if err := wire.NewWriter(&got, 0).Write(frame); err != nil {
				t.Fatal(err)
			}

			if !bytes.Equal(got.Bytes(), want) {
				t.Fatalf("%s: wrote %x, the vector says %x", vector.Doc, got.Bytes(), want)
			}
		})
	}
}
```

Package wiretest holds the conformance vectors for the plugin wire protocol, and nothing else.

Every vector states bytes a human wrote down, not bytes a codec produced. That is the whole point of the file: sdk/wire is checked against these, and an implementation in another language is checked against the same vectors published as docs/wire/plugin-wire-protocol.json by cmd/generate-wire-protocol.

A vector that a codec generated proves only that the codec agrees with itself.

### `FrameVector` {#wire-wiretest-framevector}

```go
type FrameVector struct {
    // Name identifies the vector in a failure report.
    Name string
    // Doc says what the vector holds a reader to.
    Doc string
    // Stream is the frame's stream id.
    Stream wire.StreamID
    // Kind is the frame's kind.
    Kind wire.Kind
    // HeaderHex is the nine header bytes, written by hand.
    HeaderHex string
    // PayloadHex is the payload, written by hand, for a payload small enough
    // to read.
    PayloadHex string
    // Repeat is the payload for a vector at a size boundary, and it is used
    // only when PayloadHex is empty.
    Repeat Repeat
}
```

FrameVector is one frame that every implementation encodes to the same bytes and decodes back to the same frame.
