A storage provider is where print files live before they go to a printer: a
folder on disk, or a bucket somewhere else. `storageapi` is the contract it
implements, and it is shaped so that an object store is a drop-in for the
disk-backed one. Nothing here assumes a filesystem.

The host builds a provider from `ProviderSpec` through the factory given to
`Register`, and calls the ten methods of `Provider` on behalf of a request.
Every path a provider sees is relative to its root, `/`-separated, and
untrusted; `CleanRelPath` is the one canonical form. A write is `Create`
followed by `Writer.Commit`, and nothing is published under the name until
`Commit` returns nil. `Commit` reports the length and the SHA-256 of the
bytes the provider itself wrote. A caller compares that against its own
digest and knows the object in the store is the one it sent.

The four optional abilities, `Renamer`, `Presigner`, `RangeReader` and
`LocalFiles`, are separate interfaces. A provider that serves one implements
it, and the host finds it with a type assertion through `Probe`. None is a
stub to fill with an error return.
[`storageapitest`](./storageapi-storageapitest.md) is the suite every
provider passes.

```go
package acmes3

import (
	"context"
	"path"

	"github.com/prusa3d/prusa-connect/sdk/extension"
	"github.com/prusa3d/prusa-connect/sdk/storageapi"
)

func init() {
	storageapi.Register("acme-s3", extension.Doc{
		Summary:     "Keeps print files in one S3 bucket",
		Description: "Browses and writes objects under the prefix Path names. It hands out no presigned URL.",
		Version:     "0.1.0",
		Contract:    storageapi.Contract,
		Stability:   extension.StabilityExperimental,
	}, func(spec storageapi.ProviderSpec) (storageapi.Provider, error) {
		bucket, err := openBucket(spec.Path)
		if err != nil {
			return nil, err
		}

		return &store{id: spec.ID, name: spec.Name, bucket: bucket, allowed: spec.AllowedExtensions}, nil
	})
}

// store serves the browse half and the write half. The four optional
// abilities are interfaces it does not implement, so Probe reports none.
type store struct {
	id, name string
	bucket   bucket
	allowed  []string
}

func (s *store) Name() string        { return s.id }
func (s *store) DisplayName() string { return s.name }

func (*store) Capabilities() storageapi.Caps {
	return storageapi.Caps{Browse: true, Write: true}
}

// Stat resolves the name under the store's root. A name that holds nothing
// and one that would leave the root are one refusal.
func (s *store) Stat(ctx context.Context, relPath string) (storageapi.FileInfo, error) {
	rel := storageapi.CleanRelPath(relPath)

	object, err := s.bucket.Head(ctx, rel)
	if err != nil {
		return storageapi.FileInfo{}, storageapi.ErrInvalidPath
	}

	return storageapi.FileInfo{
		Name: path.Base(rel), Path: rel, Size: object.Size, MTime: object.Modified.Unix(), SHA256: object.SHA256,
	}, nil
}

// Create refuses an extension the operator did not allow before any byte
// moves. The writer it returns publishes nothing until Commit.
func (s *store) Create(ctx context.Context, relPath string) (storageapi.Writer, error) {
	rel := storageapi.CleanRelPath(relPath)
	if err := storageapi.ValidateExtension(rel, s.allowed); err != nil {
		return nil, err
	}

	return s.bucket.Upload(ctx, rel)
}
```

The rest of `Provider` and the bucket client are the store's own and not
shown. A caller that does not read `Commit`'s error has reported success for
bytes that may never have landed. On FAT and USB media, out of space is
reported there and nowhere else.

## `storageapi` {#storageapi}


Package storageapi is the contract a storage provider implements. A separate Go module implements [Provider](#storageapi-provider) and registers it with [Register](#storageapi-register).

A path is relative to the provider's root, uses "/" as the separator and never starts with "/". The empty path is the root.

A write is Provider.Create followed by Writer.Commit. Until Commit returns nil, the name keeps its earlier content.

[Renamer](#storageapi-renamer), [Presigner](#storageapi-presigner), [RangeReader](#storageapi-rangereader) and [LocalFiles](#storageapi-localfiles) are optional. The host finds them with a type assertion. A provider that cannot serve one must not implement it.
