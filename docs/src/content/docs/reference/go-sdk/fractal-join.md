`join` has the rules of the Prusa Fractal join exchange: how a server asks to
join under another server, and how that server decides. The protocol and the
other packages are introduced on the [`fractal`](./fractal.md#prusa-fractal)
page.

Use this package when you write a transport, or a program that admits nodes.
The types are named after the protocol's words: a `Parent` is the server that
accepts others under it, and a `Joiner` is the server that asks.

- `Parent.Evaluate` takes the bytes of one join request and returns an
  `Outcome`, which is a grant or a denial. The checks run in the order the
  specification lists them, and the denial has the code of the first check
  that failed. `Parent` records every node it admits in an `AdmissionStore`,
  and `Parent.Revoke` takes an admission away
- `Joiner.Join` runs the exchange once. `Joiner.Run` keeps going: it retries
  when the denial code allows a retry, and it runs the exchange again before
  the connection credentials expire. It records the result in a
  `MembershipStore`. `Joiner.Renew` does the same for a membership the
  server already holds, without the first exchange
- `Decide` is the rule a joining server applies to a grant: adopt it, keep
  what it has, or refuse. It is a plain function with no side effect

Everything that depends on the transport is an interface that the transport
implements. `ProofVerifier` reads a request and checks its signature.
`Authorizer` decides whether the node may take the id it asks for, and `TOFU`
is one that accepts every node the first time it is seen. `Issuer` creates the
connection credentials. `RevocationHook` takes access away from a revoked node.
`Requester` sends a request and returns the reply.

```go
package gate

import (
	"context"
	"encoding/json"
	"log"
	"time"

	"github.com/prusa3d/prusa-connect/sdk/fractal"
	"github.com/prusa3d/prusa-connect/sdk/fractal/join"
)

// issuer gives an admitted server the credentials it connects with. A real
// transport creates something its broker checks. This one returns a label.
type issuer struct{}

func (issuer) Issue(
	_ context.Context, id fractal.NodeID, identity fractal.Identity, _ fractal.NodePath,
) (fractal.ConnectionCredentials, fractal.Timestamp, error) {
	expires := fractal.TimestampOf(time.Now().Add(time.Hour))

	return fractal.ConnectionCredentials(string(id) + ":" + string(identity)), expires, nil
}

// verify reads a join request. A real transport checks the signature on the
// bytes first and returns a request only when it is good.
func verify(_ context.Context, envelope []byte) (fractal.JoinRequest, error) {
	var request fractal.JoinRequest
	err := json.Unmarshal(envelope, &request)

	return request, err
}

// answer evaluates one join request that arrived at hq.
func answer(ctx context.Context, envelope []byte) (join.Outcome, error) {
	hq, err := join.NewParent(ctx, join.ParentConfig{
		Identity:   "hq-public-key",
		Path:       "hq",
		Store:      &join.MemoryAdmissionStore{},
		Verifier:   join.VerifierFunc(verify),
		Authorizer: join.TOFU{},
		Issuer:     issuer{},
	})
	if err != nil {
		return join.Outcome{}, err
	}

	outcome := hq.Evaluate(ctx, envelope)
	if !outcome.Granted {
		// Check and Cause are for this log. Only Denial goes back.
		log.Printf("denied at %s: %v", outcome.Check, outcome.Cause)
	}

	return outcome, nil
}
```

A request for the id `brno` gets a grant with the path `hq/brno`. The
application then tells its [`node`](./fractal-node.md) about the new node
through its `Admissions`. A server that was granted a path calls
`Node.SetPath` with it.

This package moves no bytes and opens no connection. It does not encode a
request, a reply or a credential, and it does not check a signature: the
transport does each of those. `MemoryAdmissionStore` and
`MemoryMembershipStore` forget everything on a restart.
`NewFileAdmissionStore` and `NewFileMembershipStore` keep the records in a
file.

Package join implements the join exchange of the Fractal protocol, in which a node asks the node above it for a place in the tree and gets a grant or a denial. This package sends no bytes itself.

Parent is the node above. It runs the checks on each join request in the order the protocol requires and answers with the code of the first check that fails. It keeps an admission record for every node it admits.

Joiner is the node that joins. It sends the request, decides with Decide whether to accept the grant, and runs the exchange again before its connection credentials expire.

A transport binding implements ProofVerifier, Authorizer, Issuer, RevocationHook and Requester, and encodes the messages.

type JoinerConfig struct {
    // Requester sends each join request and returns the answer.
    Requester Requester
    // Store keeps the Membership, so the node has it again after a restart.
    Store MembershipStore
    // NodeID is the Node ID this node asks for.
    NodeID fractal.NodeID
    // Identity is the authentication identity of this node.
    Identity fractal.Identity
    // Credential is the join credential the first request contains. Leave it
    // empty where the deployment requires none.
    Credential fractal.JoinCredential
    // Endpoint is the address this node sends its join request to.
    Endpoint Endpoint
    // HasChildren reports whether this node has admitted at least one node
    // below it. Such a node refuses a grant from a node with a different
    // identity than the one it joined before. Nil means it has admitted none.
    HasChildren func() bool
    // Credentials is a channel the application sends a new join credential
    // on. After CodeJoinUnauthorized the Joiner waits for a value and sends
    // the request again with it. When nil, Join returns a DenialError.
    Credentials <-chan fractal.JoinCredential
    // Retry chooses how the Joiner retries after a denial code. When it is
    // nil or returns false, the Joiner uses fractal.JoinRetry. A transport
    // binding sets it for a refinement whose base-code rule does not fit.
    Retry func(c fractal.Code) (fractal.Retry, bool)
    // OnGrant is called after the Joiner saved the Membership of a grant it
    // accepted, the first one and every renewal. Another Join waits until it
    // returns, so it must not call Join. It may be nil.
    OnGrant func(ctx context.Context, d Decision)
    // Extensions are the names of the protocol extensions this node runs.
    // The Joiner keeps their join data from a grant in
    // Membership.Extensions and ignores the rest.
    Extensions []fractal.Identifier
    // CheckExtensions gets the join data the Joiner kept from a grant, before
    // it saves the Membership and before OnGrant. An error refuses the grant:
    // nothing is saved and Join returns the error wrapped in
    // ErrExtensionRefused. Nil accepts every grant.
    CheckExtensions func(map[fractal.Identifier]json.RawMessage) error
    // Clock gives the time for the backoff and for the renewal. It defaults
    // to SystemClock.
    Clock Clock
    // Rand returns a random number in [0, 1). The Joiner multiplies each
    // backoff time by it. It defaults to math/rand/v2.Float64.
    Rand func() float64
    // MinBackoff is the longest the Joiner waits before its first retry. The
    // limit doubles with each retry. It defaults to one second.
    MinBackoff time.Duration
    // MaxBackoff is the highest value that limit reaches. It defaults to one
    // minute.
    MaxBackoff time.Duration
    // RenewFraction is the part of the remaining lifetime of the connection
    // credentials that Run waits before it runs the exchange again. It must
    // be above zero and at most one. It defaults to 0.75.
    RenewFraction float64
}
