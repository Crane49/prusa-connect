`node` is the engine of the Prusa Fractal protocol. One `Node` is one node of
the tree. It sends state reports upward, and it routes messages between the
node above it and the nodes below it. It runs the method calls addressed to
it, and the application calls methods on the nodes below through it. The
protocol and the other
packages are introduced on the [`fractal`](./fractal.md#prusa-fractal) page.

Use this package to make a program a Fractal node. The application supplies:

- a `Binding`, which is the transport. The node sends every message through
  its methods `SendBestEffort` and `SendDurable`. The transport gives the node
  what arrives by calling `Deliver`, `ChildConnected` and `ChildLost`. This
  package knows nothing else about a network
- an `Owner` for each interface it registers. The node calls `Snapshot` for a
  full state report, `Desire` for a property change request, and `Invoke` for
  a method call. An owner never sees a Fractal message
- an `Admissions`, which answers which node ids are directly below this node.
  A node with nothing below it leaves it out
- a [`shadow.Store`](./fractal-shadow.md), when the application reads the
  state of the nodes below

`Interface.Report` sends a state change upward. `Node.Call` runs a method on a
node below and waits for the answer. `Node.Desire` asks a node below to change
property values.

```go
package printer

import (
	"context"
	"encoding/json"
	"time"

	"github.com/prusa3d/prusa-connect/sdk/fractal"
	"github.com/prusa3d/prusa-connect/sdk/fractal/node"
)

// heater is the application behind one interface. The node calls it and
// builds every message itself.
type heater struct{}

// Snapshot answers every property, for a full state report.
func (heater) Snapshot(context.Context) (fractal.Props, error) {
	return fractal.Props{"nozzleTemp": json.RawMessage(`25.0`)}, nil
}

// Desire refuses every change, because this interface has nothing to write.
func (heater) Desire(context.Context, fractal.Props) (fractal.Props, error) {
	return nil, &fractal.Error{Code: fractal.CodeDenied, Message: "nothing here is writable"}
}

// Invoke runs a method that a node above called.
func (heater) Invoke(_ context.Context, call node.Call) (json.RawMessage, error) {
	if call.Method != "Home" {
		return nil, &fractal.Error{Code: fractal.CodeObjectNotFound, Message: "no such method"}
	}

	return json.RawMessage(`true`), nil
}

// run starts a node with no nodes below it and reports one change upward.
// transport is the package that moves the bytes.
func run(ctx context.Context, transport node.Binding) error {
	leaf, err := node.New(node.Config{Binding: transport, Path: "hq/brno/printer-1"})
	if err != nil {
		return err
	}

	handle, err := leaf.Register(node.Instance{Owner: heater{}, Name: "FDMPrinter1", Instance: "1"})
	if err != nil {
		return err
	}

	if err = leaf.Start(ctx); err != nil {
		return err
	}
	defer func() { _ = leaf.Close() }()

	// The transport calls leaf.Deliver for every message that arrives. The
	// application reports its own changes through the handle.
	now := fractal.TimestampOf(time.Now())

	return handle.Report(ctx, fractal.Props{"nozzleTemp": json.RawMessage(`200.0`)}, now)
}
```

To try a node without a network, take the transport from
[`fractaltest`](./fractal-fractaltest.md). `examples/fractal-tree` does that
with three nodes. Set `Instance.Definition` from
[`schema`](./fractal-schema.md) and the node checks every property change
request and every method parameter before it calls the owner.

This package does not run the join exchange. The application runs it with
[`join`](./fractal-join.md), then calls `SetPath` with the path it was
granted. A failed method call is not a Go error: `Call` returns the `RES`
with its error code, and a Go error means that no answer arrived. `Desire`
has no answer, so the caller watches the shadow to see whether the change
happened. The node calls an owner's methods one at a time, so a slow method
delays the next one.

## `fractal/node` {#fractal-node}

```go
import "github.com/prusa3d/prusa-connect/sdk/fractal/node"
```

Package node implements one node of the Fractal protocol, which connects servers and devices in a tree.

An application registers with a Node the interfaces it owns and calls Interface.Report when a property value changes. The Node keeps a shadow of what the nodes below reported and an ancestor shadow of what the nodes above reported. It forwards messages between the node above and the nodes below, and lets the application call a method or request a property change on a node below.

The Node contains no network code. A transport package implements Binding and calls Node.Deliver for every message it receives.

### `Binding` {#fractal-node-binding}

```go
type Binding interface {
    // SendBestEffort tries once to send d. It serves every message except
    // RPC and RES. When the link is down the transport drops the message and
    // returns nil. It must not queue or retry.
    SendBestEffort(ctx context.Context, d Dispatch) error
    // SendDurable sends an RPC or a RES. It must return only after the
    // message is stored so that a restart does not lose it. The transport
    // keeps the message while the link is down, delivers the messages for one
    // target in the order sent, and delivers one Dispatch.ID once within its
    // deduplication window.
    SendDurable(ctx context.Context, d Dispatch) error
}
```

Binding is the transport a Node sends messages through. A transport package implements it. The same package calls Node.Deliver for every message it receives, and the Connected and Lost methods when a link goes up or down. Both methods return an error that wraps ErrNoSuchLink when the transport has no link to the target.

### `Owner` {#fractal-node-owner}

```go
type Owner interface {
    // Snapshot returns the current value of every property of the instance,
    // and the time the owner read those values, never the time a value last
    // changed. Return zero to let the engine use the current time.
    Snapshot(ctx context.Context) (fractal.Props, fractal.Timestamp, error)
    // Desire applies a requested property change and returns the properties
    // whose values changed. The engine reports them. An error rejects the
    // request: change nothing.
    Desire(ctx context.Context, props fractal.Props) (fractal.Props, error)
    // Invoke runs a method and returns its result, nil for a method that
    // returns nothing. ctx ends at the expires timestamp of the request, and
    // the method must stop then.
    //
    // Return a *fractal.Error to choose the code of the answer, such as
    // fractal.CodeDenied. Any other error, and a panic, is answered with
    // fractal.CodeInternal. An owner of an instance with no Definition must
    // answer an unknown method with fractal.CodeObjectNotFound.
    Invoke(ctx context.Context, call Call) (json.RawMessage, error)
}
```

Owner is the application code behind one interface instance.

The engine calls the methods on its own goroutines. A node runs one Invoke at a time, so return quickly and do long work on another goroutine. Snapshot and Desire can run at the same time as an Invoke and as each other, so an owner must protect its own data.
